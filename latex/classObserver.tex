\doxysubsection{Detailed Description}
Abstract \doxylink{classObserver}{Observer} role. 

Event\+Flow uses a push model, so \doxylink{classObserver_a1facbbd0e34f6034d183ae9bcabbf1b0}{update()} receives the full \doxylink{structNotice}{Notice} rather than having to query the subject afterwards. Ownership\+: Subjects store observer as \textquotesingle{}non-\/owning\textquotesingle{} raw pointers, therefore observer\textquotesingle{}s lifetime is managed elsewhere. An \doxylink{classObserver}{Observer} must detach itself before its destroyed.
