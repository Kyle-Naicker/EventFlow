Detailed Description

The on-site medical station. Deliberately remains unaffected by PAUSE/RESUME/SCHEDULE_CHANGE/CANCEL/WEATHER_ALERT (when indoors) – the one leaf type that must never simply "stop" – demonstrating that identical notices produce different behaviour purely through polymorphism, not type inspection. Reacts to POWER_OUTAGE by switching to backup battery power.
