Detailed Description

Abstract Observer role.

EventFlow uses a push model, so update() receives the full Notice rather than having to query the subject afterwards. Ownership: Subjects store observer as 'non-owning' raw pointers, therefore observer's lifetime is managed elsewhere. An Observer must detach itself before its destroyed.
